\section{Additional Dataset Statistics}
\label{app:dataset_statistics}

For the main experiments, each dataset is split into training, validation, and test sets under a fixed random split. The training set is used for optimization, the validation set is used for checkpoint and threshold selection, and the test set is used only for final reporting. Table~\ref{tab:data_split_appendix} reports the label distribution of each split. The split-level distribution is reported in the appendix because the main text focuses on aggregate dataset differences, while these counts document the exact processed split files used by the experiments.
